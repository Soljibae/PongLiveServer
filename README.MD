# Pong Live Server

## 개요

Unity 기반의 PC / Android 크로스플레이 퐁 게임과 C# 서버를 함께 구현하는 소규모 온라인 게임 서버 프로젝트입니다.

이 프로젝트는 단순한 퐁 게임 제작이 아니라, **Dedicated Game Server**, **Backend Server**, **PostgreSQL**, **Redis**를 분리해 실제 온라인 게임 서비스에 가까운 서버 구조를 학습하고 구현하는 것을 목표로 합니다.

전체 흐름은 다음과 같습니다.

```text
Windows Client / Android Client
        │
        ▼
Backend Server
- 로그인
- 토큰 발급
- 매치메이킹
- 전적 조회
- 랭킹 조회
        │
        ▼
Dedicated Game Server
- 플레이어 입력 처리
- 공 이동 / 충돌 처리
- 점수 판정
- 매치 종료
- 결과 보고
        │
        ▼
PostgreSQL / Redis
- 유저 데이터
- 매치 기록
- 랭킹
- 매칭 큐
- 임시 상태 데이터
```

---

## 프로젝트 목적

이 프로젝트는 유니티에서의 서버 환경 학습 및 크로스플레이 구현 학습을 목적으로 제작합니다.

주요 목표는 다음과 같습니다.

- Unity 기반 1 vs 1 퐁 게임 구현
- PC / Android 크로스플레이 지원
- Dedicated Server 기반 실시간 게임 진행
- 클라이언트는 입력만 전송하고, 서버가 공 이동 / 충돌 / 점수를 판정
- ASP.NET Core Backend Server를 통한 로그인, 토큰 발급, 매치메이킹, 전적 저장
- PostgreSQL을 이용한 유저 / 매치 / 전적 데이터 저장
- Redis를 이용한 매칭 큐, 캐시, 랭킹 데이터 관리
- 게임 서버와 백엔드 서버를 분리한 구조 구현
- 외부 서버 배포 및 클라이언트 접속 확인
- 개발 중 발생한 문제 상황과 해결 과정을 기록

## 현재 문제 상황
